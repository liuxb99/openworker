# Case 0003 玉井橋：正射影像與街景黑圖語義驗收缺口

日期：2026-08-18

## 背景

Case 0003 目前已把 DTM/DEM 幾何、Blender REAL 地形與 SceneX REAL Region Pack 主線跑通，但實體成果審查又暴露兩個影像層缺口：

1. SceneX 地表仍是純色材質，沒有把原設計中的正射影像作為地表貼圖帶進 Region Pack / SceneX。
2. 街景 `master-panorama.png` 可以產生非空 PNG、SHA256 與 provider provenance，但實體畫面仍可能是一片黑；現有機械驗收只驗證檔案、瓦片、尺寸、雜湊與來源，不驗證影像內容是否可讀。

這兩項都不能算 Case 0003 完成。

## 缺口 A：正射影像未進 SceneX 地表材質鏈

目標架構應維持「DTM/DEM 決定地形幾何，正射影像決定地表外觀」。不能用灰色、綠色或其他純色材質替代真實正射影像後仍宣告 SceneX 地形成果完成。

本輪先將其標記為待追溯既有設計的整合缺口。必須先從 `Terrain_To_DXF` / 相關歷史文檔與提交找回既有正射影像取得、裁切/投影、GeoTIFF/PNG/瓦片及地理邊界契約，再決定是恢復既有 Region Pack 欄位或補新版契約。不得在未確認舊設計前另造一套互不相容格式。

最終驗收至少要求：

- 正射影像為真實影像，不是 placeholder / 單色圖。
- 影像範圍、CRS/地理邊界與 terrain grid/AOI 可追溯。
- Region Pack 明確攜帶影像資產及其座標/UV 對應。
- SceneX REAL 載入後，地形表面可辨識出真實影像紋理。
- 影像資產 SHA256、來源、產生工具版本與 SceneX evidence 可追溯。
- 貼圖與地形沒有明顯翻轉、錯位、拉伸或全黑。

## 缺口 B：街景黑圖仍可通過機械驗收

`Terrain_To_DXF/internal/streetview/tiles_stitch.go` 的 `StitchMasterPanorama` 現況主要驗證：

- tile set 完整；
- tile SHA256 正確；
- tile 可解碼；
- tile 尺寸合理；
- stitched PNG 可寫入；
- output bytes / SHA256 / index SHA256 可產生。

但沒有任何像素語義可見性檢查，因此「所有瓦片都合法但畫面近純黑」仍可產生一份結構上合法的 `streetview-master-panorama/v1` evidence。

### 修復原則

在 owning repo `Terrain_To_DXF` 直接把影像語義可見性變成 stitch 的 fail-closed contract，而不是只在 Case 0003 workflow 外面做一次性判斷。

Evidence 應增加可機器判讀的內容指標，例如：

- `luma_mean`
- `luma_stddev`
- `luma_min` / `luma_max` 或 robust percentile range
- `non_black_pixel_ratio`
- `coarse_luma_range` / coarse block structure
- `semantic_visible=true|false`

閾值要以「拒絕純黑/近純黑/近單色輸出」為目的，避免因瀏覽器 UI、少量文字或 attribution 本身讓黑畫面誤通過。

### 街景驗收規則

Case 0003 街景只有在以下條件同時成立時才能 PASS：

1. Google/指定 provider provenance 與 attribution 驗證通過；
2. panorama/tile 來源和 SHA 完整；
3. stitched image 非空、可解碼；
4. semantic visibility gate 通過；
5. 實體畫面可看到有意義的道路/環境內容，不是黑圖、空圖或只剩 browser chrome；
6. ChatGPT 對實體街景圖做最終語義審查。

## Case 0003 重跑範圍

這次不需要重跑已驗證的 DTM/AOI/Blender。只重跑受影響的影像與呈現階段：

1. 街景 provider capture / tile acquisition / stitch；
2. 正射影像取得與地形貼圖封裝（在找回既有設計後）；
3. SceneX Region Pack / REAL browse；
4. fresh review revision；
5. Google Drive 實體成果審查；
6. PASS 後才進 WorkLedger / Delivery Revision；
7. 最後仍需 `Open-Case0003-SceneX.bat` 實機打開 SceneX 看到正確成果。
