## 2. GitHub 短命令 transport 的正確定位

GitHub 短命令 transport 不是架構缺口，本身是目前 ChatGPT 無法直接到達 ODA 時的合法 control transport：

```text
ChatGPT
  -> command-requests/oda.json
  -> short-lived GitHub Action
  -> ODA openworkerctl/openworker.exe
  -> Go OpenWorker Local Supervisor / Case Engine
  -> go-tool :8848 durable queue / tool execution
  -> OpenWorker :8787 durable ledger
  -> JSON receipt
  -> command-results/oda/<request_id>/final.json
  -> ChatGPT read-back
```

GitHub 只承載高階短命令與 transport receipt；它不是 business executor、不是 long-lived controller、不是 artifact authority。
