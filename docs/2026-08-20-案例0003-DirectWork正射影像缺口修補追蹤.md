## 為什麼這個修補必要

新版 Case 0003 的 authority 順序必須是：

```text
GitHub 傳輸密語
-> DirectWork 建 durable work
-> UL7 executor 使用本機可驗證 owning repo
-> producer 產 fresh REAL artifact
-> durable evidence / receipt
```

如果 executor 還依賴 GitHub workflow token 去取得另一 private repo，business work 仍被 transport credential 綁住，與 local-first DirectWork 設計不一致。
