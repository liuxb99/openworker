### 7.4 Windows process kernel 真實修復

REAL ODA tests 连续暴露并修复：

1. `go.sum` 缺失导致 clean machine `go test ./...` fail-closed。
2. Windows `cmd /C` 双重 quoting 导致 quoted executable / PowerShell exit code 误判。

- GitHub workflow completed ≠ Case completed。
- Git commit ≠ OpenWorker business evidence。
- `queued_for_oda` ≠ ODA 已执行 command。
- `oda_accepted` ≠ Case business step 完成。

- Python 只允许作为 leaf runtime；不得恢复为 Case controller fallback。
