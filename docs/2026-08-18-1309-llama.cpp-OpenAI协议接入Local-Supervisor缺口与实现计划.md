## 1. 当前缺口

OpenWorker 已有 Supervisor durable backend，但本机 llama.cpp 仍只是 OpenAI-compatible inference server。当前缺少真正把模型接入 OpenWorker 架构的 Agent Host。

缺口：

```text
llama.cpp OpenAI client               MISSING
Supervisor system contract injection  MISSING
startup session/bootstrap/recover      MISSING
OpenAI tool definitions                MISSING
tool_call dispatch loop                MISSING
tool result -> model continuation      MISSING
heartbeat / attention observe loop     MISSING
config / CLI entry                     MISSING
contract tests                         MISSING
```

因此目前不能只靠启动 `llama-server.exe` 就让模型自动知道如何操作 OpenWorker。

## 2. 正确边界

```text
llama.cpp
= OpenAI-compatible inference server

Local Supervisor Host
= Agent runtime / tool-call loop / system contract

go-tool / OpenWorker API
= tool surface

OpenWorker Go
= durable execution authority
```

禁止把第二套 scheduler、PID manager 或 durable queue 写进 Local Supervisor Host。

## 3. 目标实现

新增：

```text
coworker/local_supervisor.py
```

职责：

```text
load config
-> connect llama.cpp OpenAI endpoint
-> create new transient session_id
-> create OpenWorker supervisor session
-> recover durable snapshot
-> inject fixed Supervisor system contract
-> expose OpenWorker tools using OpenAI function tools
-> run tool_call loop
-> feed tool results back to llama.cpp
-> heartbeat current supervisor session
-> observe attention without blocking long jobs
```

## 4. OpenAI-compatible endpoint

默认：

```text
http://127.0.0.1:8080/v1
```

OpenAI SDK：

```text
base_url = llama.cpp /v1
api_key = local dummy key
model = configured local model alias
```

Local Supervisor Host 不依赖 OpenAI cloud。

## 5. Bootstrap Contract

每次启动必须创建新的 `session_id`，然后：

```text
POST /v1/supervisor/session
POST /v1/supervisor/recover
GET  /v1/supervisor/attention
GET  /v1/supervisor/jobs
GET  /v1/cluster/agents
GET  /v1/cluster/capabilities
```

模型 context 只得到恢复后的事实；OpenWorker durable state 仍是 authority。

## 6. System Contract

固定告诉模型：

- 你是 Local Supervisor，不是 worker；
- OpenWorker 是 job/process/queue/lock/progress 的唯一 durable authority；
- 禁止自己以 shell/Start-Process 管理长任务；
- submit 得 durable ACK 后不要阻塞等待；
- Action completed != job succeeded；
- fixed-machine job 不得漂移；
- failed/stale/blocked 先看 durable state/negative knowledge，再 retry/replan；
- decision receipt 不保存 chain-of-thought。

## 7. 第一批 Tool Surface

Local Supervisor Host 直接把已有 OpenWorker 能力包装成 OpenAI function tools：

```text
supervisor_snapshot
supervisor_jobs
supervisor_attention
supervisor_recover
supervisor_decision
cluster_status
cluster_agents
cluster_capabilities
job_status
job_progress
job_submit
job_cancel
job_retry
queue_drain
```

Tool implementation 复用 `OpenWorkerNodeClient`，不复制 HTTP/scheduler logic。

## 8. Agent Loop

```text
messages + tools
-> llama.cpp chat.completions
-> assistant tool_calls
-> Local Supervisor Host dispatch
-> append role=tool result
-> llama.cpp continuation
-> until no tool_calls
```

必须有 max tool rounds，避免模型无限工具循环。

## 9. 非阻塞原则

Local Supervisor Host 不等待 long job 完成。模型 submit 后继续观察其他 jobs / attention。

后续持续 supervision 使用 heartbeat + attention interval，而不是把一次 OpenAI request 挂到业务任务结束。
