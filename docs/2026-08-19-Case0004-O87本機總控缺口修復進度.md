## 4. 缺口三：local supervisor bootstrap 被工具 checkout 綁死

### REAL 現象

O87 已完成 compile/build/install，卻在：

```text
Bootstrap per-machine durable local queue
```

失敗，log：

```text
OpenWorker local checkout not found
install-gtr-local-work-runtime.ps1:38
throw "$Name local checkout not found"
```

### 根因

`install-gtr-local-work-runtime.ps1` 把 OpenWorker、ComfyX、ComfyX-Studio、OpenMAIC 等工具 checkout 當成整個 local supervisor 的強制 bootstrap 前置條件。

這與最新版架構衝突。go-tool-runtime :8848 的 durable queue / claim / executor supervisor 應能獨立啟動；各工具 root 只決定對應 local capability 是否註冊，不應讓 4+4 control plane 整體死亡。

`internal/localexec.Registry` 本身已是正確設計：有 root 才註冊對應 capability；沒有 root 時，核心 supervisor probe 等能力仍可存在。

### 修復

- commit：`62b5f4a9773b9e08c32b260a44e3215ed5e057e6`
- installer 改為：
  - 明確傳入的 tool root 若無效：fail-closed；
  - 未明確指定且本機找不到：warning + 空 root；
  - 對應 capability 不註冊；
  - 不阻塞 go-tool-runtime :8848 / queue / agent / executor supervisor 啟動；
  - ComfyX output root 同樣改為 capability-level optional authority，而不是 control-plane hard gate。
